가림 상자는 눌러서 켜고 끄고, 끌어서 옮기고, 모서리로 크기를 바꿔요. 빈 곳을 드래그하면 직접 가려요.

있던 사진도

사진을 여러 장 불러오거나, 메뉴 막대 아이콘에 끌어다 놓거나, 클립보드 이미지를 바로 가려요. 아이폰 사진(HEIC)도 돼요.

모자이크 · 블러 · 막대

가리는 방식을 골라요. 블러는 배경이 흐릿하게 비치고, 가장 확실한 건 검은 막대예요.

내 맥 안에서만

글자 인식도 맥에 내장된 기능으로 해요. 이미지를 어디에도 보내지 않고, 원본 캡처는 바로 지워요.

Install

3분이면 시작해요*

  1. GarimShot.dmg를 열고 가림샷을 Applications 폴더로 끌어 놓아요.
  2. 처음 열 때 "확인할 수 없음" 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 눌러요. 공증 전 베타라 처음 한 번만 필요해요.
  3. 처음 캡처할 때 화면 및 시스템 오디오 녹음 권한을 켜고, 가림샷을 한 번 다시 열어요.
  4. ⌃⇧4로 찍어 보세요. 가려진 결과를 ⌘C로 복사해서 바로 붙여 넣으면 돼요.

FAQ

자주 묻는 질문

캡처한 이미지가 어디로 전송되나요?

아니요. 글자 인식과 얼굴 인식 모두 맥에 내장된 Vision 기능으로 내 맥 안에서 처리해요. 가리기 전 원본 캡처는 처리 직후 지우고, 앱이 꺼질 때도 남은 파일을 정리해요.

모자이크를 풀어서 원래 숫자를 알아낼 수 있나요?

모자이크 칸을 글자보다 크게 잡고 매번 무작위 잡음을 섞어서, 숫자를 하나씩 대입해 비교하는 방법으로도 맞히기 어렵게 했어요. 그래도 가장 확실한 건 검은 막대예요. 가린 결과를 다시 글자 인식으로 읽어 하나도 읽히지 않는지 검사하고 있어요.

놓치는 경우도 있나요?

글씨가 아주 작거나 흐리면 놓칠 수 있어요. 그래서 복사 전에 편집 창에서 한 번 확인하게 했고, 빠진 곳은 드래그해서 바로 가릴 수 있어요. 놓친 사례를 알려 주시면 다음 버전에서 잡을게요.

왜 화면 녹음 권한이 필요한가요?

macOS에서 다른 앱 창이 보이는 화면을 찍으려면 이 권한이 꼭 필요해요. 캡처할 때만 쓰고, 화면을 녹화하거나 저장해 두지 않아요.

베타가 끝나면 유료인가요?

정식 출시 후에는 한 번 결제로 계속 쓰는 라이선스로 판매할 예정이에요. 베타 때 의견을 보내 주신 분께는 혜택을 드릴게요.
