가림샷
개인정보 처리방침

시행일: 2026년 11월 23일 (베타)

1. 수집하는 정보

가림샷은 개인정보를 수집하지 않아요. 캡처하거나 불러온 이미지는 사용자의 맥 안에서만 처리되고, 어떤 서버로도 전송되지 않아요.

2. 이미지 처리

글자 인식과 얼굴 인식은 macOS에 내장된 Vision 기능으로 맥 안에서 해요. 가리기 전 원본 캡처는 임시 폴더에 잠깐 저장했다가 처리 직후 지우고, 앱이 꺼질 때도 남은 파일을 정리해요. 가린 결과는 사용자가 복사하거나 저장할 때만 클립보드나 선택한 폴더에 남아요.

3. 권한 사용

화면 및 시스템 오디오 녹음 권한은 사용자가 캡처할 때 화면을 찍는 데에만 써요. 화면을 계속 녹화하거나 보관하지 않아요.

4. 설정

단축키, 가리는 방식, 저장 위치 같은 설정은 맥 안(~/Library/Application Support/GarimShot)에만 저장돼요.

5. 문의

GitHub Issues로 남겨 주세요.
