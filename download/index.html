설치하고 실행하기

Windows (Windows 10/11 · x64)

① chzzk-win-x64.exe를 내려받아 더블클릭 → ② 설치가 자동으로 끝나고 "치지직"이 바로 열려요 → ③ 시작 메뉴·바탕화면의 Chzzk로 다시 열 수 있어요.
첫 화면에 라이브와 다시보기 목록이 나오고, 카드를 누르면 재생돼요.

macOS (macOS 12 이상 · Apple Silicon / Intel 공용)

① chzzk-mac-universal.dmg를 열고 → ② 치지직을 Applications 폴더로 끌어 놓기 → ③ Launchpad에서 실행해요.
처음 한 번 "열지 않음" 경고가 뜨면 아래 "설치가 막힐 때"를 보세요.

Android (Android 7.0 이상 · 모든 CPU, 네이티브 라이브러리 없음)

① chzzk-android.apk를 휴대폰에서 내려받아 열기 → ② "이 출처 허용"을 켜고 설치 → ③ 앱 목록의 치지직을 실행해요.

설치가 막힐 때

macOS: "확인되지 않은 개발자" 경고가 떠요

아직 Apple 공증 전이라 처음 한 번만 경고가 떠요.
시스템 설정 → 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르면 이후로는 바로 열려요.

Windows: "Windows의 PC 보호" 창이 떠요

서명 인증서가 없어서 SmartScreen이 막는 거예요. 추가 정보 → 실행을 누르면 설치돼요.

Android: "알 수 없는 앱 설치" 차단이 떠요

Play 스토어 밖에서 받은 앱이라 처음 한 번 허용이 필요해요. 경고 창의 설정 → "이 출처 허용"을 켠 뒤 뒤로 가서 설치를 누르세요.

라이브 송출할 때 카메라가 안 켜져요

처음 송출할 때 카메라·마이크 권한을 물어봐요. 거절했다면 macOS는 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 "치지직"을 켜 주세요.
