Install

설치하고 실행하기

Windows

chzzk-win-x64.exe를 내려받아 더블클릭하면 설치가 자동으로 끝나고 바로 열려요. 시작 메뉴와 바탕화면의 Chzzk로 다시 열 수 있어요.

macOS

chzzk-mac-universal.dmg를 열고 치지직을 Applications 폴더로 끌어 놓은 뒤 Launchpad에서 실행해요. Apple Silicon과 Intel 공용이에요.

Android

휴대폰에서 chzzk-android.apk를 받아 열고 "이 출처 허용"을 켠 뒤 설치를 눌러요. 앱 목록의 치지직으로 실행해요.

Help

설치가 막힐 때

macOS: "확인되지 않은 개발자" 경고가 떠요

아직 Apple 공증 전이라 처음 한 번만 경고가 떠요. 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르면 이후로는 바로 열려요.

Windows: "Windows의 PC 보호" 창이 떠요

서명 인증서가 없어서 SmartScreen이 막는 거예요. 추가 정보 → 실행을 누르면 설치돼요.

Android: "알 수 없는 앱 설치" 차단이 떠요

Play 스토어 밖에서 받은 앱이라 처음 한 번 허용이 필요해요. 경고 창의 설정 → "이 출처 허용"을 켠 뒤 뒤로 가서 설치를 누르세요.

라이브 송출할 때 카메라가 안 켜져요

처음 송출할 때 카메라·마이크 권한을 물어봐요. 거절했다면 macOS는 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 "치지직"을 켜 주세요.
